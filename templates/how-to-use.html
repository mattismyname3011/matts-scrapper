How to Use Media Scraper

Learn how to extract publicly exposed download links from supported pages.

1

Open a supported page

2

Copy the URL

Copy the address of the page from your browser.

3

Paste the URL

Return to Media Scraper and paste the URL into the URL field.

4

Click Scrape

The application will process the page and display supported publicly exposed links.
