# Media Scraper Web

A lightweight web application for extracting publicly exposed download
links from supported media pages.

## Supported Sources

- Kusonime
- Driverays

## Features

- Direct URL scraping
- No site-wide search
- Dark responsive UI
- Mobile friendly
- Download links grouped by quality
- Copy links
- Open links in a new tab
- FastAPI backend
- Background scraping
- Source URL validation

## Requirements

- Python 3.10+
- pip

## Installation

Create a virtual environment:

```bash
python -m venv .venv
```
